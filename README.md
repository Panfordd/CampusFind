# CampusFind — Ashesi Lost & Found

CampusFind is a responsive lost-and-found website prototype designed for the Ashesi University community. It aims to make it easier for students to report lost or found items, browse reports, and find information about missing belongings.

This project was developed as part of a Web Technologies course.

## Features

- **Homepage:** Introduces CampusFind and displays recently reported items.
- **Browse Items:** Displays sample lost-and-found reports with search and filtering options.
- **Report an Item:** Allows users to enter details about lost or found items and validates the form using JavaScript.
- **Item Details:** Displays additional information about a selected item.
- **Responsive Design:** Supports desktop and mobile screen sizes.
- **Navigation:** Includes a mobile hamburger menu and back navigation buttons.

## Technologies Used

- **HTML5** — Page structure and forms
- **CSS3** — Styling and responsive layouts
- **JavaScript** — DOM manipulation, arrays, objects, functions, loops, search, filtering, and form validation
- **Git and GitHub** — Version control and source code management

## How to Run the Project

1. Download or clone the GitHub repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Use the navigation menu to explore the different pages.

No database or server setup is required.

## How CampusFind Works

1. **Browse Reports:** Users can explore sample lost-and-found reports.
2. **Search and Filter:** Users can search by item name or location and filter by lost or found status.
3. **View Details:** Users can select an item to see its category, location, date, and description.
4. **Report an Item:** Users can complete a form and receive a validation confirmation.

## Project Limitations

CampusFind is a frontend prototype developed for academic purposes.

- The website uses fictional sample reports stored in a JavaScript array.
- Form submissions are validated but are not permanently saved.
- There is no database, user authentication, or real-time report management.
- The website is not an official Ashesi University service.
